# Ćwiczenia – Indeks

Witaj w sekcji ćwiczeń! Wybierz moduł, aby zacząć:

| Moduł | Plik | Opis |
|---|---|---|
| GitHub Copilot CLI | [copilot-cli-exercises.md](copilot-cli-exercises.md) | Ćwiczenia z `gh copilot explain` i `gh copilot suggest` |
| Prompt Engineering | [prompt-engineering-exercises.md](prompt-engineering-exercises.md) | Techniki tworzenia efektywnych promptów |

## Jak korzystać z ćwiczeń?

1. Przeczytaj najpierw odpowiedni przewodnik w katalogu [`docs/`](../docs/).
2. Wykonuj ćwiczenia w podanej kolejności – poziomy są ułożone od prostszych do trudniejszych.
3. Nie spiesz się – celem jest zrozumienie, nie szybkie przejście przez listę.
4. Zanotuj własne obserwacje i wnioski – to najlepsza forma uczenia się.

## Postęp

Możesz śledzić swój postęp, oznaczając checkboxy w plikach ćwiczeń:
- `[ ]` – ćwiczenie do wykonania  
- `[x]` – ćwiczenie ukończone
