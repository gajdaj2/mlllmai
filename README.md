## 🚀 Szybki start

### Wymagania

- Konto GitHub z dostępem do GitHub Copilot
- [GitHub CLI (`gh`)](https://cli.github.com/) zainstalowane lokalnie
- Rozszerzenie Copilot dla `gh`:

```bash
gh extension install github/gh-copilot
```

### Weryfikacja instalacji

```bash
gh copilot --version
gh copilot explain "co to jest prompt engineering"
```
